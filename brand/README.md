# ctrorec brand

The brand name is written **`ctrorec`**, lowercase, in product interfaces and documentation.

## Masters

- `ctrorec-logo.svg` — primary horizontal lockup, transparent background
- `ctrorec-mark.svg` — compact recording mark, transparent background
- `ctrorec-favicon.svg` — simplified small-size mark
- `ctrorec-favicon-64.png` — rendered small-size fallback
- `ctrorec-logo.png` and `ctrorec-mark.png` — rendered transparent PNGs
- `ctrorec-logo-source.png` — selected source concept; not for production layout

Application copies live in `apps/web/public/brand`; the simplified favicon is `apps/web/public/favicon.svg`.

## Colour

| Token          | Hex       | Use                                   |
| -------------- | --------- | ------------------------------------- |
| Forest         | `#205346` | Primary mark, wordmark, key accents   |
| Clay           | `#AD4B32` | Recording cue and small emphasis only |
| Warm off-white | `#F4F5F1` | Preferred light surface               |

Do not stretch, redraw, recolour, add gradients, or add shadows to the masters. Keep clear space around the lockup. Use the mark alone only where the ctrorec name is already established or space is constrained. Use the simplified favicon at very small sizes.
